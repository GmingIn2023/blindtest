# Blind Test — produit

**Ce que c'est** : un blind test multijoueur façon Kahoot, entre amis, dans le même salon. L'hôte joue sur un ordinateur (ou une télé) qui diffuse le son ; chaque joueur buzze et répond depuis son téléphone. Gratuit, sans compte, sans installation.

**Qui l'utilise** : une bande d'amis ou une famille en soirée. Pas des « gamers » : des gens qui veulent rire ensemble en 2 minutes de mise en place. Âges mélangés, téléphones variés (beaucoup d'iPhone), connexion Wi-Fi parfois moyenne.

**Le moment d'usage** : soirée, lumière tamisée, téléphone à une main, attention partagée avec les autres. On lit l'écran en un coup d'œil ; on n'explore pas de menus.

**Ce qui compte**
1. Démarrer vite : créer → partager le code (ou un QR) → jouer.
2. Comprendre sans explication : un seul geste évident par écran (Buzzer, Choisir, Lancer).
3. Fiabilité : le son sort toujours, personne ne reste bloqué, une coupure réseau se rattrape.
4. Chaleur humaine : ça doit ressembler à une soirée vinyle entre amis, pas à un tableau de bord.

**Ton** : tutoiement, phrases courtes, un peu d'humour, jamais de jargon technique.

**Modes de jeu** : Standard (buzzer + titre), Instru (sans voix, ×1,5), Playlist (deviner à qui est la chanson), Paroles (mots révélés un à un).

**Contraintes techniques** : HTML/CSS/JS sans framework, hébergé sur GitHub Pages, Firebase Realtime Database, musique via iTunes/Deezer (extraits de 30 s). Les IDs et la logique JS des pages sont le contrat entre les écrans : ne jamais les casser.
